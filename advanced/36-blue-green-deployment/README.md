## 🎯 Goal
Implement blue-green deployments for an existing app (e.g. project 22) to ship with zero downtime.

## 📋 Requirements
- [ ] Run the new version in a separate container alongside the current one
- [ ] Switch traffic to the new container only once it is ready

## 🌟 Stretch goals
- [ ] CI/CD pipeline that deploys automatically on push
- [ ] Monitoring for both the app and the deployment process

## 🎓 What you'll learn
- Zero-downtime deployment of containerized apps
- Deploying without data loss
