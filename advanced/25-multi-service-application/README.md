# Multi-Service Application

> **Level:** Advanced · **Topic:** Docker · **Status:** ⬜ Not started<br>
> **Brief:** [roadmap.sh/projects/multiservice-docker](https://roadmap.sh/projects/multiservice-docker)

## 🎯 Goal
Build a production-like multi-service Docker setup using advanced Docker features.

## 📋 Requirements
- [ ] Services: React frontend, Node.js/Express API, MongoDB, Redis cache, Nginx reverse proxy
- [ ] Define everything with Docker Compose
- [ ] Custom base images for the web app and API
- [ ] Multi-stage build for the web app
- [ ] A Docker network for service-to-service traffic
- [ ] Volumes for DB and cache persistence
- [ ] Docker secrets for sensitive data (e.g. DB password)
- [ ] Health checks for every service
- [ ] Optimized Dockerfiles (image size, build time)
- [ ] Logging and log rotation for all services

## 🎓 What you'll learn
- Advanced Docker: networks, volumes, secrets, multi-stage builds
- Best practices for complex containerized environments
