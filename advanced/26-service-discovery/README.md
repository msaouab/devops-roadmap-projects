# Service Discovery

> **Level:** Advanced · **Topic:** DevOps · **Status:** ⬜ Not started<br>
> **Brief:** [roadmap.sh/projects/service-discovery](https://roadmap.sh/projects/service-discovery)

## 🎯 Goal
Learn service discovery by wiring dummy microservices together through Consul.

## 📋 Requirements
- [ ] Three dummy services (A, B, C), each exposing e.g. `/info` that returns the service name and current timestamp
- [ ] Each service registers itself with Consul on startup
- [ ] An API gateway as the single entry point, which discovers services through Consul's DNS interface or HTTP API and routes requests
- [ ] Consul as the registry and the gateway's single source of truth

## 🎓 What you'll learn
- How services register with and are queried from Consul
- Service-to-service communication in microservices
