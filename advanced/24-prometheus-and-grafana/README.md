# Prometheus and Grafana

> **Level:** Advanced · **Topic:** Monitoring · **Status:** ⬜ Not started<br>
> **Brief:** [roadmap.sh/projects/monitoring](https://roadmap.sh/projects/monitoring)

## 🎯 Goal
Build a monitoring stack: Prometheus collects metrics, Grafana visualizes them.

## 📋 Requirements
- [ ] A server running an app with dependencies (e.g. Nginx, Node.js); reuse a previous one or create a new one
- [ ] **Prometheus:** install; configure scrape intervals, targets and retention
- [ ] Exporters for system metrics (CPU, memory, disk, network) and services (Nginx, MySQL, MongoDB…)
- [ ] Custom exporter or instrumentation for app-specific metrics
- [ ] **Grafana:** install, add Prometheus as a data source
- [ ] Dashboards: system overview, app metrics, custom PromQL panels
- [ ] Configure Grafana authentication and authorization

## 🌟 Stretch goals
- [ ] Alerting rules and notification channels (email, Slack)
- [ ] Recording rules
- [ ] Prometheus service discovery
- [ ] Loki for logs, correlated with metrics
- [ ] A custom exporter for one of your services

## 🎓 What you'll learn
- Running a production-style monitoring stack
- PromQL and dashboard design
- Observability: metrics, alerts and logs
