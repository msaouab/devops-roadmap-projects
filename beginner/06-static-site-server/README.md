# Static Site Server

> **Level:** Beginner · **Topic:** Nginx · **Status:** ⬜ Not started<br>
> **Brief:** [roadmap.sh/projects/static-site-server](https://roadmap.sh/projects/static-site-server)

## 🎯 Goal
Serve a static site from a Linux server with Nginx, and deploy updates with `rsync`.

## 📋 Requirements
- [ ] Create a remote Linux server (DigitalOcean, AWS, …) and connect over SSH
- [ ] Install and configure Nginx to serve a static site
- [ ] Build a simple page with HTML, CSS and an image
- [ ] Use `rsync` to push the local site to the server
- [ ] Serve it on a domain if you have one, otherwise on the server IP
- [ ] Write a `deploy.sh` script that runs the sync in one step

## 🎓 What you'll learn
- Setting up an Nginx web server
- Deploying static files with `rsync`
