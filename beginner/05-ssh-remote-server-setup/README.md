# SSH Remote Server Setup

> **Level:** Beginner · **Topic:** SSH · **Status:** ⬜ Not started<br>
> **Brief:** [roadmap.sh/projects/ssh-remote-server-setup](https://roadmap.sh/projects/ssh-remote-server-setup)

## 🎯 Goal
Provision a remote Linux server and configure key-based SSH access to it.

## 📋 Requirements
- [ ] Create a Linux server on any provider (DigitalOcean, AWS, …)
- [ ] Generate two new SSH key pairs and add both to the server
- [ ] Connect with each key: `ssh -i <path-to-private-key> user@server-ip`
- [ ] Add a `~/.ssh/config` entry so `ssh <alias>` works
- [ ] Document the steps in this README; **never commit private keys**

## 🌟 Stretch goals
- [ ] Install and configure `fail2ban` against brute-force attacks

## 🎓 What you'll learn
- Generating and managing SSH keys
- Configuring SSH client aliases
- Basic remote server access
