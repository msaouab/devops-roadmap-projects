# Simple Monitoring

> **Level:** Beginner · **Topic:** Monitoring · **Status:** ⬜ Not started<br>
> **Brief:** [roadmap.sh/projects/simple-monitoring-dashboard](https://roadmap.sh/projects/simple-monitoring-dashboard)

## 🎯 Goal
Set up a real-time monitoring dashboard on a Linux system with Netdata.

## 📋 Requirements
- [ ] Install Netdata on a Linux system
- [ ] Monitor CPU, memory usage and disk I/O
- [ ] Open the dashboard in a browser
- [ ] Customize at least one dashboard element (add or change a chart)
- [ ] Create an alert, e.g. CPU usage above 80%
- [ ] Automate it: `setup.sh` (install), `test_dashboard.sh` (generate load), `cleanup.sh` (uninstall and clean up)

## 🎓 What you'll learn
- System monitoring basics
- Configuring alerts
- Scripting repeatable setup and teardown
