# GitHub Pages Deployment

> **Level:** Beginner · **Topic:** CI/CD · **Status:** ⬜ Not started<br>
> **Brief:** [roadmap.sh/projects/github-actions-deployment-workflow](https://roadmap.sh/projects/github-actions-deployment-workflow)

## 🎯 Goal
Write a GitHub Actions workflow that deploys a static site to GitHub Pages: an intro to CI/CD.

## 📋 Requirements
- [ ] Create a repo (e.g. `gh-deployment-workflow`)
- [ ] Add an `index.html` with a "Hello, GitHub Actions!" message
- [ ] Add a `README.md` explaining the project
- [ ] Add `.github/workflows/deploy.yml`
- [ ] Deploy only on pushes to `main`, and only when `index.html` changes
- [ ] Site is live at `https://<username>.github.io/<repository-name>/` and updates on each change

## 🌟 Stretch goals
- [ ] Build a richer site (e.g. a portfolio) with a static site generator such as Hugo, Jekyll or Astro

## 🎓 What you'll learn
- GitHub Actions and GitHub Pages
- Writing CI/CD workflows with path and branch filters
