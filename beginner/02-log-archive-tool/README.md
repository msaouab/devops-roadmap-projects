# Log Archive Tool

> **Level:** Beginner · **Topic:** CLI · **Status:** ⬜ Not started<br>
> **Brief:** [roadmap.sh/projects/log-archive-tool](https://roadmap.sh/projects/log-archive-tool)

## 🎯 Goal
Build a CLI tool that compresses a log directory into a dated archive, keeping the system clean while old logs stay available. On Unix systems logs usually live in `/var/log`.

## 📋 Requirements
- [ ] Usage: `log-archive <log-directory>`
- [ ] Compress the logs into a `tar.gz` file stored in a new archive directory
- [ ] Name archives with a timestamp, e.g. `logs_archive_20240816_100648.tar.gz`
- [ ] Record the date and time of every archive run in a log file

## 🌟 Stretch goals
- [ ] Email the user when an archive is created
- [ ] Ship archives to a remote server or cloud storage
- [ ] Run it on a schedule (cron)

## 🎓 What you'll learn
- Working with files and directories from the shell
- Building a small, reusable CLI tool
- Using `tar` for compression
