# Linux Server Setup

> **Level:** Intermediate · **Topic:** Linux · **Status:** ⬜ Not started<br>
> **Brief:** [roadmap.sh/projects/linux-server-setup](https://roadmap.sh/projects/linux-server-setup)

## 🎯 Goal
Take a fresh Ubuntu VPS and harden it into a production-ready server.

## 📋 Requirements
- [ ] **Users:** a non-root sudo user for all admin work
- [ ] **SSH:** key-based login; disable password auth
- [ ] **Firewall:** UFW allowing only SSH (22) by default; know how to add rules
- [ ] **Updates:** upgrade packages and enable `unattended-upgrades`
- [ ] **Hardening:** Fail2Ban for SSH brute-force protection
- [ ] **Config:** correct timezone and a meaningful hostname
- [ ] **Services:** show `systemctl` status/start/stop/enable
- [ ] **Logs:** use `journalctl` and know the common files in `/var/log/`
- [ ] **Verify:** run through a security checklist confirming each item

## 🎓 What you'll learn
- Securing Linux against common attacks
- Users, permissions, SSH and firewalls
- Keeping servers patched
