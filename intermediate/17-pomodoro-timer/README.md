# Pomodoro Timer

> **Level:** Intermediate · **Topic:** Frameworks · **Status:** ⬜ Not started<br>
> **Brief:** [roadmap.sh/projects/pomodoro-timer](https://roadmap.sh/projects/pomodoro-timer)

## 🎯 Goal
Build a Pomodoro timer web app: focused work intervals separated by short breaks.

## 📋 Requirements
- [ ] Start, stop and resume the timer
- [ ] Configurable intervals: work 25 min, short break 5 min, long break 15 min after 4 sessions
- [ ] Show the current session type (Work / Short Break / Long Break)
- [ ] Count completed work sessions
- [ ] Play a sound when a session ends
- [ ] Responsive and accessible (keyboard navigation, ARIA labels)
- [ ] Plain HTML/CSS/JS or a framework (React, Vue, Angular); modular code with clear state management
- [ ] Optional: deploy to GitHub Pages, Vercel or Cloudflare Pages

## 🎓 What you'll learn
- Frontend state management
- Building interactive, accessible UIs
- Deploying a frontend app
